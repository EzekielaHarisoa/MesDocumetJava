# HashMap
 > pas de doublons (sauf valeur)
 > pas thread-safe
 > acces direct
 > valeur nulles (jusqu à une cle null , et eventuelement plusieurs valeurs)


# TreeMap
 > pas de doublons pas de valeur double
 > pas thread-safe
 > d'acces direct
 > ordonnée

 # Methodes
 > put(<key>,<value>);
 > get(<key>)
 > containsKey(<key>)
 > containsValue(<value>)
 > keySet() : parcourir les keys
